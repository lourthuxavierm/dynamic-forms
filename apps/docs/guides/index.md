Guides are task-oriented paths for building applications. The supported new-user
journey uses React HTML, the current browser-native renderer.

## New-user journey

Follow these pages in order:

1. [Introduction](../getting-started/introduction.md)
2. [Choose an integration](../getting-started/choose-an-integration.md)
3. [Installation](../getting-started/installation.md)
4. [Create your first schema](../getting-started/first-schema.md)
5. [Render your first form](../getting-started/first-form.md)
6. [Add validation](../getting-started/validation.md)
7. [Handle submission](../getting-started/submission.md)
8. [Next steps](../getting-started/next-steps.md)

The shorter [quick start](../getting-started/quick-start.md) remains available
for readers already familiar with the architecture.
