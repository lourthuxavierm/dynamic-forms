# Dynamic Forms documentation

Build schema-driven forms with a framework-independent Core, React integration, and accessible browser-native controls.

::: warning Pre-1.0 status
The repository is at version 0.1.0. Core, React, HTML, and Examples are implemented; adapter and DevTools packages remain placeholders until their inventories say otherwise.
:::

## Start from trusted information

- Complete the [quick start](./getting-started/quick-start.md) to render and submit your first validated form.
- Read the [documentation standards](./documentation-standards.md) to understand maturity and verification.
- Review [package traceability](./documentation-inventory.md) before adopting an integration.
- Use the [HTML package guide](./packages/html.md) for native controls and layouts.

1. Package manifests
2. Exported TypeScript APIs
3. Runtime registries
4. Tests and runnable examples
5. Roadmaps for future intent
