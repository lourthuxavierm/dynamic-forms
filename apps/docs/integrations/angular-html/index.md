# Angular HTML integration

- Status: Experimental baseline renderer
- Owner: Angular HTML maintainers
- Last verified: 2026-08-27
- Applies to: `@dynamic-form-engine/angular-html` 0.1.0

`@dynamic-form-engine/angular-html` renders an initial browser-native control set from
an Angular `DynamicFormFacade`. It ships standalone OnPush components, an
immutable experimental registry utility, semantic error markup, and optional
CSS. It does not yet match React HTML's complete control/layout contract.
