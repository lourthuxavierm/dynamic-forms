# Angular HTML layouts

- Status: Deferred
- Owner: Angular HTML maintainers
- Last verified: 2026-08-27
- Applies to: Future Angular HTML releases

The initial component renders top-level fields in schema order. It does not yet
implement the proposed layout registry, structural object/array renderer,
sections, grids, tabs, actions, or summaries. Layout APIs remain Phase 9 design
material until implementation and accessibility tests exist.
