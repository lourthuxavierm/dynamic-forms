# React HTML controls and values

- Status: Documented v1 contract
- Owner: React HTML maintainers
- Last verified: 2026-08-27
- Applies to: `V1_HTML_FIELD_TYPES`

The default registry guarantees 42 stable leaf controls across core inputs,
selection, temporal, specialized, and file/media groups. Object and array are
stable structural fields outside that count. Experimental registered controls
remain explicitly separated from the v1 tuple.

Use the canonical [control reference](../../controls/index.md) for emitted
values, configuration, validation, accessibility, and limitations. The
[deep-reference catalogue](./deep-references.md) maps the package-local control,
temporal, specialized, file/media, keyboard, and structural contracts.
