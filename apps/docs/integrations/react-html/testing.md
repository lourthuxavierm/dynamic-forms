# Testing React HTML

- Status: Implemented guidance
- Owner: React HTML and quality maintainers
- Last verified: 2026-08-27
- Applies to: React HTML v1

Render `FormProvider` and `HtmlForm` with a focused schema, interact using
accessible roles and labels, and assert Core values plus visible error/state
changes. Cover registry overrides, structural paths, layouts, keyboard behavior,
async work, object URL cleanup, error boundaries, direction, and submission.

Release verification includes unit/integration tests, public API and v1-contract
tests, accessibility automation and manual review, performance budgets, package
compatibility verification, playground typecheck/build, and documentation
tests. The [deep references](./deep-references.md) identify each package-local
checklist and contract.
