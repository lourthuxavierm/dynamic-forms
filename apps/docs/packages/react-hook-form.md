# React Hook Form package

Status: Release-ready for React 18/19 and React Hook Form 7.52.0 or newer.

`@dynamic-form-engine/rhf` keeps React Hook Form authoritative while Dynamic
Forms evaluates schemas, validation, conditions, dependencies, and data sources.
It provides the typed provider, resolver, field bridge, schema renderer, array
and lifecycle helpers, serialization, diagnostics, and renderer-neutral control
registry.

Compatibility is enforced against React 18 and 19 plus the minimum and current
supported RHF 7 releases. Chromium coverage verifies submission, validation,
conditional and structural fields, async race handling, keyboard operation,
Strict Mode, and accessibility. The release gate also validates the packed ESM,
CommonJS, and declaration artifacts.

See the [React Hook Form integration guide](../integrations/rhf) and
[generated API reference](../api/generated/rhf).
