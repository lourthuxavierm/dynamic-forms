# @dynamic-forms/core

Framework-independent dynamic form engine.

The core package contains the business logic required to create and manage schema-driven forms.

It does not depend on React, Material UI, Angular, Vue, or another UI framework.

---

## Features

- Form schema
- Field definitions
- Form state
- Field state
- Field registry
- Validation
- Conditions
- Dependencies
- Data sources
- Events
- Extensibility

---

## Install

```bash
pnpm add @dynamic-forms/core
