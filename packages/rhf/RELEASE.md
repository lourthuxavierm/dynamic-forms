# RHF adapter release notes

## 0.1.0

Initial release-ready React Hook Form 7 adapter.

- Typed schema-driven `RHFForm` and renderer-neutral control registry.
- Bidirectional Dynamic Forms/RHF state projection and resolver integration.
- Conditions, dependent data sources, nested fields, arrays, reset, and serialization.
- React 18/19 and supported RHF 7 compatibility automation.
- Chromium workflow and accessibility coverage through the RHF playground.
